==========================================
       WebSistExamenes - INSTALL.txt
==========================================

REQUISITOS
----------
1. Node.js 18+ (obligatorio)
2. npm (incluido con Node)
3. MongoDB Atlas (base de datos en la nube)
4. Archivo .env en la raíz del proyecto
5. NGINX (HTTP2 en producción)

------------------------------------------
PUERTOS UTILIZADOS EN EL PROYECTO
------------------------------------------

- Servidor HTTP (Express):          http://localhost:3001
- Servidor HTTPS (Express)          http://localhost:3000
- HTTP/2 (NGINX):  https://localhost   (puerto 443)



------------------------------------------
1. DESCARGA DEL PROYECTO
------------------------------------------

Clonar o descargar ZIP:
    git clone https://github.com/MiguelHC456/WebSistExamenes.git
    cd WebSistExamenes

------------------------------------------
2. INSTALAR DEPENDENCIAS
------------------------------------------

    npm install

------------------------------------------
3. CONFIGURAR VARIABLES DE ENTORNO (.env)
------------------------------------------

El archivo .env debe crearse en la raíz del proyecto.

contenido:

MONGODB_URI=mongodb+srv://marceloargandona_db_user:runaFehu,1001@cluster0.esconbo.mongodb.net/quiz_app?retryWrites=true&w=majority&appName=Cluster0
PORT=3000
JWT_SECRET=superclaveultrasecreta123
NODE_ENV=development

------------------------------------------
3.1 EJEMPLO DE CONEXIÓN A MONGO ATLAS
------------------------------------------

Para obtener tu URL:

1. Entra a https://cloud.mongodb.com
2. Selecciona tu cluster → "Connect"
3. Elige: "Connect your application"
4. Copia el string que empieza con:

   mongodb+srv://...

Ejemplo REAL usado en este proyecto:

    MONGODB_URI=mongodb+srv://marceloargandona_db_user:runaFehu,1001@cluster0.esconbo.mongodb.net/quiz_app?retryWrites=true&w=majority&appName=Cluster0

Otros valores requeridos:

    PORT=3001
    JWT_SECRET=superclaveultrasecreta123
    NODE_ENV=development

4. UBICACIÓN DE CERTIFICADOS HTTPS (*.pem)
------------------------------------------

Los certificados usados por NGINX deben almacenarse en:

    /certs/cert.pem
    /certs/cert-key.pem
    /certs/ca.pem   (opcional)

Ejemplo de estructura del proyecto:

    WebSistExamenes/
    ├── certs/
    │   ├── cert.pem
    │   └── cert-key.pem
    ├── server.js
    ├── routes/
    ├── models/
    ├── middleware/
    ├── package.json
    └── .env

6. CONFIGURAR NGINX COMO REVERSE PROXY
------------------------------------------

Instalar NGINX en Ubuntu (WSL):

    sudo apt install nginx

Archivo a editar:

    /etc/nginx/sites-available/default

Contenido recomendado:

    server {
        listen 80;
        listen [::]:80;
        return 301 https://$host$request_uri;
    }

    server {
        listen 443 ssl http2;
        listen [::]:443 ssl http2;

        server_name localhost;

        ssl_certificate     /etc/nginx/certs/cert.pem;
        ssl_certificate_key /etc/nginx/certs/cert-key.pem;

        ssl_protocols TLSv1.2 TLSv1.3;
        ssl_prefer_server_ciphers on;

        location / {
            proxy_pass http://winhost:3001;
            proxy_http_version 1.1;
            proxy_set_header Host $host;
            proxy_set_header X-Real-IP $remote_addr;
            proxy_set_header X-Forwarded-Proto https;
        }
    }

Validar configuración:

    sudo nginx -t

Reiniciar NGINX:

    sudo service nginx restart

Acceso HTTPS final:

    https://localhost/api/...
