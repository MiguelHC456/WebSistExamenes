==========================================
       WebSistExamenes - INSTALL.txt
==========================================

REQUISITOS
----------
1. Node.js 18+ (obligatorio)
2. npm (incluido con Node)
3. MongoDB Atlas o MongoDB local
4. Archivo .env en la raíz del proyecto

------------------------------------------
PUERTOS UTILIZADOS EN EL PROYECTO
------------------------------------------

- Servidor HTTP (desarrollo):       http://localhost:3001
- Servidor HTTPS interno:           https://localhost:3001
- Servidor HTTP/2 (NGINX):          https://localhost   (puerto 443, sin especificar)

------------------------------------------
1. DESCARGA DEL PROYECTO
------------------------------------------

Clonar o descargar ZIP:
    git clone https://github.com/MiguelHC456/WebSistExamenes.git
    cd WebSistExamenes

------------------------------------------
2. INSTALAR DEPENDENCIAS
------------------------------------------

    npm install

------------------------------------------
3. CONFIGURAR VARIABLES DE ENTORNO (.env)
------------------------------------------

Contenido mínimo:

    MONGODB_URI=mongodb+srv://marceloargandona_db_user:runaFehu,1001@cluster0.esconbo.mongodb.net/quiz_app?retryWrites=true&w=majority&appName=Cluster0
    PORT=3001
    JWT_SECRET=superclaveultrasecreta123
    NODE_ENV=development

------------------------------------------
4. EJECUTAR LOS SERVIDORES
------------------------------------------

Servidor HTTP (puerto 3001):
    node server.js

Servidor HTTPS (puerto 3001, si está habilitado):
    node server-https.js

Servidor HTTP/2 (NGINX, puerto 443):
    https://localhost

------------------------------------------
5. RESUMEN DE RUTAS HTTP/HTTPS
------------------------------------------

HTTP (3001):
    http://localhost:3001/api/...

HTTPS (3000):
    https://localhost:3001/api/...

HTTP/2 (443 – vía NGINX):
    https://localhost/api/...

------------------------------------------
6. MANUAL DE USO DE LA API
------------------------------------------

ID usado: 69319326a7ddd215e62a0caa

=====================
     6.1 LOGIN
=====================

POST http://localhost:3001/api/auth/login
Body:
{
  "correo": "admin@mail.com",
  "password": "123456"
}

Salida:
{
  "msg": "Login exitoso",
  "token": "<JWT_TOKEN>"
}

=============================
  6.2 LISTAR USUARIOS (GET)
=============================

GET http://localhost:3001/api/usuarios

Salida:

[ Lista de usuarios ]
